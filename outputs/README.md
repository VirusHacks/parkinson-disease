# Outputs

This folder stores generated artifacts and supporting analysis for the benchmark.

## Structure

- `benchmark/`
  Public benchmark reports, JSON summaries, and calibration summaries.
- `search/`
  Policy-search artifacts such as tremor rescue sweeps.
- `runs/`
  Raw command outputs from smoke tests, calibration runs, and inference runs.
- `analysis/`
  Narrative analysis documents and benchmark review notes.

## Main files

- `benchmark/benchmark_eval.md`
  Human-readable public and held-out benchmark report.
- `benchmark/benchmark_eval.json`
  Machine-readable benchmark results.
- `benchmark/phase6_10_summary.md`
  Summary of the benchmark hardening and calibration work.
- `search/tremor_policy_search.md`
  Human-readable tremor policy sweep summary.
- `search/tremor_policy_search.json`
  Machine-readable tremor policy sweep results.

These files are regenerated by the evaluation and search scripts under `parkinsons_Motor/evaluation/`.

## Run artifacts

- `runs/local_inference_report.md`
  Combined local inference report from `run_local_inference.py`.
- `runs/taskwise_inference_summary.md`
  One-task-at-a-time inference summary from `run_taskwise_inference.py`.
